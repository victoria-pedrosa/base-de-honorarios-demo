# Base De Honorarios

> Projeto de portfólio de **Victória Pedrosa** (Automação, Processos e Dados). Automação desenvolvida para um escritório de contabilidade; **esta é uma versão com dados fictícios** — nomes, CNPJs, e-mails e IDs internos foram substituídos.

## Problema de negócio
O monitor de honorários precisava de score e de um formulário para os dados do piloto.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Coleta manual de dados. | Módulos de score/gatilhos e formulário web que grava direto nas abas. |

## Ganho
- Dados do piloto coletados com padrão.

## Tecnologias
APIs REST, E-mail automático, Gatilhos agendados, Google Apps Script, Google Sheets, HTML/JavaScript, SQLite, Web App (HtmlService)

## Arquivos
- `FormularioPreenchimento.html`
- `Modulo_10_MotorDeScore.gs`
- `Modulo_11_FormularioPreenchimento.gs`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
